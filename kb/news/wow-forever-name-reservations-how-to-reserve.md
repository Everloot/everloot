**TL;DR:** WoW: Forever name reservations open Tuesday, October 27 and run through November 3, Pacific time. You need an eligible upgrade purchase, you can reserve up to 3 characters, and names go first come, first served. Pick your ruleset and names now so you are ready when the window opens.

## What Blizzard confirmed
Per [Blizzard's announcement](https://news.blizzard.com/en-us/article/24303866/claim-your-world-of-warcraft-forever-character-names), the reservation window opens October 27 and closes November 3, the day before WoW: Forever launches on November 4.

- **Who can reserve:** players with an eligible upgrade purchase.
- **How many:** up to 3 characters.
- **How names are given out:** first come, first served. Popular names will go in the first hour.

For exact start times in each region, see [Wowhead's start-times guide](https://www.wowhead.com/forever/news/how-to-reserve-your-world-of-warcraft-forever-character-name-on-october-27th-383515).

## What to do before Tuesday
- **Choose a ruleset first.** A name is tied to a ruleset, and switching later means a new character. Read our [rulesets explainer](/news/wow-forever-rulesets-explained-pvp-rp-pvp-hardcore).
- **Have backups.** Write down two or three spellings for each name you want.
- **Plan your 3 slots.** If you want a main plus alts, decide which class and faction each one is before you log in.

*News recap. Everloot has no addon data for name reservations.*
