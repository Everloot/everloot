Item pages can now show names from the current game's files or the Warcraft Wiki before players have uploaded matching observations. Open {item:2589}, or browse the [item database](/database/items), to see the names alongside the information available for each item.

A name from the game files or the wiki tells us what an item is called. It does not prove that a particular enemy drops it, that a vendor sells it, or that it is obtainable in the current game. Those questions need their own evidence. When a page has little player data, treat the missing details as unknown.

## Finding an item

Start with the [item categories](/database/items) and open an item page. Named items in the current build also appear in the database sitemap so search engines can discover them. Being listed in a sitemap does not mean a search engine has indexed the page yet.

For Blizzard's own announcements and build updates, use the [changes timeline](/changes). The timeline and the item database answer different questions: one records published changes, while the other helps you inspect individual items.

## Helping fill the gaps

The [addon page](/addon) explains how to install Everloot. After you log out, follow the [upload instructions](/upload) to contribute the observations your addon recorded. Real reports help fill the gaps between what the game files name and what players encounter.

If something looks wrong, note where the page says the name came from and what you saw in game.
